# Changelog

## 0.1.0 — 2026-08-30

Initial MBrutals release.

- Neo Brutalism design tokens and pastel palette.
- Responsive container, grid and utility system.
- Buttons, badges, cards, alerts, hero, navbar.
- Forms, tables, breadcrumbs, pagination, list groups.
- Accordion, tabs, dropdown, modal, offcanvas, toast, tooltip.
- Avatar, skeleton, spinner, switch, progress and carousel.
- Optional vanilla JavaScript data API.
- CDN-ready `dist/` files.
