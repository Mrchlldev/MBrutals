# Changelog

## 1.2.0 — 2026-08-31

- Redesigned the entire visual system around a more modern Neo Brutalist aesthetic.
- Increased visual hierarchy, stronger hard shadows, bold rounded geometry, and pastel surfaces.
- Added a more distinctive navigation, hero, card, alert, form, modal, toast, tabs, accordion, pricing, stats, timeline, steps, file, and empty-state system.
- Expanded responsive utilities and layout helpers.
- Improved focus states and reduced-motion support.
- Added safer text handling for the toast API.
- Added public JS helpers for modal, offcanvas, carousel, and toast.
- Updated package metadata and version to 1.2.0.
