GET STARTED

Install MBrutals.

For a CDN, upload the contents of dist/ to your server. The demo server exposes the same files at root paths.

1. CDN stylesheet

Replace the domain with your own CDN hostname.

Recommended production URL
<link rel="stylesheet" href="https://cdn.example.com/mbrutals.min.css">
<link rel="stylesheet" href="https://cdn.example.com/mbrutals.min.css">

2. JavaScript

Only needed for interactive components such as modals, drawers, tabs and toasts.

<script src="https://cdn.example.com/mbrutals.min.js"></script>

3. First component

No initialization is required.

<button class="mb-btn mb-btn-yellow mb-hover">  Hello MBrutals →</button>
