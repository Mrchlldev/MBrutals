# MBrutals v1.6.2

Modern Neo Brutalist CSS + vanilla JavaScript framework.

## Run docs
```bash
npm install
npm start
```

Open `/`, `/docs`, or `/components/buttons`.

## CDN
Upload `dist/` to your CDN:
- `mbrutals.min.css`
- `mbrutals.min.js`

Then:
```html
<link rel="stylesheet" href="https://cdn.example.com/mbrutals.min.css">
<script src="https://cdn.example.com/mbrutals.min.js"></script>
```

No framework required.
