Why MBrutals?

Built for people who hate boring UI.

MBrutals mengambil konsep Neo Brutalism dan mengemasnya menjadi utility dan component system yang bisa langsung digunakan pada HTML biasa.

01 ✦

Plain CSS

Tidak bergantung pada React, Vue, Next.js, atau framework frontend lainnya.

02 ⚡

Bold by Default

Thick borders, hard shadows, rounded blocks, dan typography yang punya karakter.

03 ↗

Responsive

Grid dan component tetap nyaman digunakan dari desktop sampai mobile.

04 ◈

Utility First

Spacing, display, flex, typography, sizing, dan utility lainnya tersedia langsung.

05 ✓

Vanilla JS

Modal, dropdown, toast, tabs, accordion, dan komponen interaktif tanpa dependency.

06 ♡

CDN Ready

Build project dengan local file atau langsung host MBrutals di CDN milikmu sendiri.

Simple Setup

That's it.

Tidak ada konfigurasi rumit. Masukkan stylesheet dan mulai gunakan class MBrutals di HTML kamu. 

<!-- Add MBrutals -->

<link
  rel="stylesheet"
  href="mbrutals.min.css"
>

<button
  class="mb-btn mb-btn-blue"
>
  Hello MBrutals
</button>
Get MBrutals

Your next UI starts here.

Download MBrutals, host file-nya di server atau CDN kamu, dan gunakan di project HTML apa pun.

npm install mbrutals Copy
